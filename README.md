# Sluurp examples

Small apps built with [Sluurp](https://github.com/SluurpHQ/releases). Each is a folder you run as it is:

```sh
sluurp serve --public todos/app
```

| Folder | What it shows |
| --- | --- |
| [todos](todos/app) | A to-do list everybody edits at once, with live cursors, in two files. |
| [sheet](sheet/app) | A spreadsheet several people edit at once; a cell is locked while someone types in it. |
| [docs-site](docs-site/app) | A landing page and Markdown docs with a generated sidebar, published as plain files with `sluurp static`. |
| [blog](blog/app) | Posts in two languages, tags, feeds and a sitemap, rendered on the server. |
| [server-components](server-components/app) | A server-rendered page, a server function called from the browser, and islands. |
| [wiki](wiki/app) | A whole wiki on Pages: nested pages, history, a link graph, books and PDF export. |
| [ui-library](ui-library/app) | Your own components beside the UI kit's, with stories and their tests. |
